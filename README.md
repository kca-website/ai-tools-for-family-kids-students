# AI Tools for Family, Kids & Students

Ανεξάρτητο, δωρεάν, δίγλωσσο (EL/EN) εργαλείο που βοηθά **γονείς, μαθητές (6–18) και
εκπαιδευτικούς** να καταλάβουν **ποια AI εργαλεία είναι κατάλληλα, ασφαλή και χρήσιμα
ανά ηλικία — και για ΠΟΙΑ δουλειά**.

> Ο πυρήνας του project είναι *"ποιο εργαλείο για ποια δουλειά, σε ποια ηλικία"*.
> Η ασφαλής χρήση/εποπτεία είναι ένα κομμάτι του περιεχομένου, όχι το κέντρο βάρους.

Ανεξάρτητο project. Δεν σχετίζεται με κανέναν οργανισμό, μουσείο ή προμηθευτή AI εργαλείων.

---

## Δομή περιεχομένου

**3 ηλικιακές ζώνες:**

| Ζώνη | Ηλικίες | Χαρακτηριστικά |
|---|---|---|
| 🧒 Δημοτικό | 6–12 | Περιορισμένα εργαλεία, έμφαση σε επίβλεψη |
| 🎒 Γυμνάσιο | 12–15 | Περισσότερα εργαλεία, αρχή αυτόνομης χρήσης |
| 🎓 Λύκειο | 15–18 | Σχεδόν πλήρες φάσμα, έμφαση σε σωστή χρήση |

**2 "λεωφορεία" περιεχομένου ανά ζώνη:**

- 👪 **Γονιός / Εκπαιδευτικός** — τι να ξέρει, πώς να εποπτεύσει
- 🧑‍🎓 **Μαθητής** — πώς να χρησιμοποιήσει σωστά (γλώσσα προσαρμοσμένη στην ηλικία)

## Αρχιτεκτονική

- **Vanilla JS** — χωρίς framework, χωρίς build step
- `index.html` — δομή σελίδας
- `data.js` — όλο το περιεχόμενο (ζώνες, ρόλοι, εργαλεία, path-specific καθοδήγηση)
- `app.js` — λογική rendering, πλοήγηση, δίγλωσσο σύστημα (EL/EN)
- `styles.css` — στυλ, χωρίς frameworks
- **Static site** — no backend, no API calls, no database
- Deploy: **Vercel** (static hosting)

### Οργάνωση δεδομένων (path-first)

Το `data.js` είναι οργανωμένο **ανά ζώνη/ρόλο** (όχι ανά εργαλείο):

```
PATHS[zoneId][roleId] = {
  introEl / introEn: εισαγωγικό κείμενο,
  tools: [
    {
      toolId: αναφορά στο TOOLS,
      useCaseEl/En: για ΤΙ δουλειά είναι κατάλληλο ΕΔΩ,
      howToEl/En: πώς να το χρησιμοποιήσεις / πώς να εποπτεύσεις,
      cautionEl/En: προαιρετική προσοχή
    }
  ]
}
```

Κάθε εργαλείο ζει μία φορά στο `TOOLS` (όνομα, link, κατηγορία) και μπορεί να
εμφανίζεται σε πολλαπλά paths με διαφορετικό `useCase`/`howTo` per ζώνη.

## Τοπική ανάπτυξη

Δεν χρειάζεται build step. Απλά σέρβιρε τον φάκελο στατικά:

```bash
python3 -m http.server 8000
# ή
npx serve .
```

Άνοιξε `http://localhost:8000`.

## Deploy (Vercel)

1. Push το repo στο GitHub
2. Import στο [vercel.com](https://vercel.com) → "New Project" → επίλεξε το repo
3. Framework preset: **Other** (static, no build command)
4. Deploy

Το `vercel.json` στο root ήδη ορίζει static config.

## Προσθήκη νέου εργαλείου

1. Πρόσθεσε entry στο `TOOLS` object (`data.js`) με μοναδικό `id`
2. Πρόσθεσε reference σε ένα ή περισσότερα `PATHS[zone][role].tools` arrays,
   με ζώνη-specific `useCase` / `howTo` / (προαιρετικά) `caution`
3. Refresh — δεν χρειάζεται build
