# AI Tools for Family, Kids & Students

Ανεξάρτητο, δωρεάν, δίγλωσσο (EL/EN) εργαλείο για **γονείς, μαθητές 6–18 και εκπαιδευτικούς**.

Ο στόχος είναι να βοηθά τον χρήστη να καταλάβει:
- πού χρειάζεται εξάσκηση,
- ποιο AI ή συμπληρωματικό εκπαιδευτικό εργαλείο ταιριάζει σε συγκεκριμένη ανάγκη,
- πώς να το χρησιμοποιήσει με καθοδήγηση αντί για έτοιμη λύση,
- ποιοι ηλικιακοί/λογαριασμιακοί περιορισμοί ισχύουν.

> Βασική αρχή: η AI πρέπει να βοηθά τον μαθητή να καταλάβει, να εξασκηθεί και να σκεφτεί, όχι απλώς να του παραδίδει έτοιμη εργασία.

Ανεξάρτητο project. Δεν αποτελεί επίσημο προϊόν ή συνεργασία των παρόχων που αναφέρει.

---

## Τι περιλαμβάνει σήμερα

- 3 ηλικιακές ζώνες: Δημοτικό, Γυμνάσιο, Λύκειο
- ξεχωριστή προβολή Γονιού/Εκπαιδευτικού και Μαθητή
- προτάσεις εργαλείων ανά ζώνη, ρόλο και μάθημα
- Διαγνωστικό Χάρτη εξάσκησης
- Μονοπάτια Μάθησης
- Prompt Generator
- προαιρετική AI Βοήθεια / Βοηθό Γονέα μέσω Puter, με ηλικιακό gating
- στατικές SEO σελίδες για εργαλεία
- ενότητα προσβασιμότητας
- συλλογή σχολικών εννοιών στην Ελληνική Νοηματική Γλώσσα (ΕΝΓ)
- δίγλωσσο περιεχόμενο EL/EN
- PWA/service worker και Vercel Web Analytics

## Δομή περιεχομένου

| Ζώνη | Ηλικίες | Χαρακτηριστικά |
|---|---|---|
| 🧒 Δημοτικό | 6–12 | έμφαση σε γονική/εκπαιδευτική καθοδήγηση |
| 🎒 Γυμνάσιο | 12–15 | περισσότερη αυτονομία, με σαφείς ηλικιακούς κανόνες |
| 🎓 Λύκειο | 15–18 | ευρύτερο φάσμα εργαλείων και υπεύθυνη αυτόνομη χρήση |

**2 ρόλοι ανά ζώνη:**
- 👪 **Γονιός / Εκπαιδευτικός**
- 🧑‍🎓 **Μαθητής**

## Αρχιτεκτονική

- **Vanilla JS**: χωρίς framework και χωρίς υποχρεωτικό build step
- `index.html`: βασική δομή της εφαρμογής
- `data.js`: εργαλεία και path-specific περιεχόμενο
- `curriculum-data.js`, `official-curriculum-data.js`, `curriculum-2026-2027-expansion.js`, `gel-2026-2027-update.js`: σχολικό/curriculum layer
- `quiz-data.js`: Διαγνωστικός Χάρτης
- `learning-paths-data.js`: Μονοπάτια Μάθησης
- `tutor.js`: AI Βοήθεια / Βοηθός Γονέα
- `app.js`: βασικό rendering και navigation
- `site-integrity-overrides.js`, `site-postfix.js`: συμβατότητα/μεταγενέστερες διορθώσεις που σταδιακά ενοποιούνται στη βασική λογική
- `styles.css`: κύρια εμφάνιση
- `/tools/`: στατικές landing pages εργαλείων
- `sign-language.html` + σχετικά JS: προσβάσιμο υλικό ΕΝΓ
- `methodology.html`: μεθοδολογία επιλογής και επαλήθευσης περιεχομένου

## Τοπική ανάπτυξη

Δεν χρειάζεται build step:

```bash
python3 -m http.server 8000
# ή
npx serve .
```

Άνοιξε `http://localhost:8000`.

## Deploy

## Ενημέρωση εργαλείων

Για κάθε εργαλείο ελέγχονται κατά προτεραιότητα:
- επίσημοι όροι ηλικίας / γονικής συναίνεσης,
- τρόπος πρόσβασης και λογαριασμός,
- δωρεάν/επί πληρωμή λειτουργίες,
- σχολική χρησιμότητα,
- επίσημη τεκμηρίωση και πηγές.

Αναλυτικά: `methodology.html`.
