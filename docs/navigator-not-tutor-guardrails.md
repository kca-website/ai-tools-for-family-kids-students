# AI Tools 4 Kids — Navigator, not Tutor

## Product identity

**Το AI Tools 4 Kids δεν διδάσκει το παιδί. Το βοηθά να βρει τον σωστό τρόπο, εργαλείο και επόμενο βήμα για να μάθει.**

Primary flow:

**Τι θέλω να κάνω → τι μου ταιριάζει → ποιο εργαλείο να χρησιμοποιήσω → πώς να το χρησιμοποιήσω σωστά.**

Secondary flow:

**Πού δυσκολεύομαι → τι χρειάζεται εξάσκηση → ποια βοήθεια ή εργαλείο μπορεί να με ξεκολλήσει.**

Avoid framing the product as: **«Μπες εδώ και θα σου κάνω εγώ το μάθημα.»**

## Six product guardrails

### 1. Basic use stays account-free
The core guide, tool selection and Practice Map must not require an account.

### 2. No student dossier or server-side progress history
Do not build a parent dashboard, longitudinal student profile, grades history or persistent server-side learning record as a core feature.

### 3. Do not become the subject teacher
The site should not become «the AI teacher for Maths / Physics / Essay writing». AI Help may scaffold and unstick, but the core value remains selection, routing and correct use of tools.

### 4. AI Help is optional, not the destination
AI Help stays available — and free where technically possible — but it must not become the main reason the product exists or the dominant homepage promise.

### 5. New features should help the user choose or use something better
A feature fits the product when it improves **choice, routing, safe use, understanding of a tool or the next step**. It does not fit when it replaces the teacher or turns the site into an LMS/tutor.

Litmus examples:
- “AI grades an essay and gives a score” → **No**.
- “Show which tools can help improve an essay and how to prompt them” → **Yes**.
- “Store every test and show a parent progress chart” → **No**.
- “Practice Map says fractions need work and routes to 2 suitable resources” → **Yes**.

### 6. The first screen must have one clear primary route
Do not put 5–6 equal CTAs in the hero. The first screen must make the product identity obvious within a few seconds.

Current hierarchy:
1. **Primary CTA:** Find the right AI tool.
2. **Secondary CTA:** Not sure what you need? Use the short Practice Map / Quick Check.
3. Lower on the page: task-first routes such as PDF study, research with sources, flashcards, presentation, reading/English and creative projects.
4. AI Help, parent routes, Greek Sign Language and other specialist routes remain visible but secondary.

This is a positioning rule as much as a UI rule. A product can be technically “not a tutor” and still look like one if the hero is dominated by assessment, learning loops or chat.

## EXPOSE > BUILD, with one constraint
Expose existing strong assets — including hidden learning gaps and task routes — **without allowing one feature to redefine the whole product identity**.

The homepage should feel like a **map of choices**, not a learning platform.
