Google Antigravity

Δημιουργία εκπαιδευτικών εφαρμογών με AI — Πρακτικός οδηγός για εκπαιδευτικούς

Οδηγός για ενήλικους εκπαιδευτικούς που θέλουν να δοκιμάσουν τον προγραμματισμό με τη βοήθεια AI.

Άνοιξε την επίσημη σελίδα

Τι είναι;

Το Google Antigravity είναι περιβάλλον ανάπτυξης εφαρμογών με AI agents. Μπορεί να βοηθήσει στη συγγραφή και επεξεργασία κώδικα, στην κατασκευή μικρών εφαρμογών και στον έλεγχο του αποτελέσματος. Δεν είναι απλό chatbot ούτε έτοιμη εκπαιδευτική πλατφόρμα.

Πώς μπορεί να βοηθήσει έναν εκπαιδευτικό;

  • Κατασκευή διαδραστικού quiz επανάληψης.
  • Δημιουργία μικρών εκπαιδευτικών ιστοσελίδων και δραστηριοτήτων.
  • Δοκιμές και βελτιώσεις ψηφιακού υλικού.
  • Εισαγωγή σε πραγματικές πρακτικές ανάπτυξης λογισμικού.

Βήματα για μια πρώτη δοκιμή

  1. Άνοιξε την επίσημη σελίδα και εξέτασε τις απαιτήσεις εγκατάστασης και του λογαριασμού.
  2. Χρησιμοποίησε έναν νέο, ξεχωριστό φάκελο δοκιμών, όχι το παραγωγικό υλικό του σχολείου.
  3. Ζήτησε: «Δημιούργησε ένα απλό quiz 10 ερωτήσεων Φυσικής με ανατροφοδότηση μετά από κάθε απάντηση, με HTML, CSS και JavaScript, χωρίς συλλογή προσωπικών δεδομένων».
  4. Ζήτησε να σου δείξει προεπισκόπηση και να ελέγξει την ορθότητα των απαντήσεων.
  5. Δοκίμασε ο ίδιος όλες τις ερωτήσεις και διορθώσε τυχόν λάθη πριν από χρήση στην τάξη.

Δοκίμασε αυτό το prompt

Δημιούργησε μια απλή, προσβάσιμη, δίγλωσση (Ελληνικά/Αγγλικά) ιστοσελίδα quiz για τα κλάσματα της Ε΄ Δημοτικού. Να περιλαμβάνει 8 ερωτήσεις, εξηγήσεις μετά την απάντηση, κουμπί «Προσπάθησε ξανά» και σωστή εμφάνιση σε κινητά. Να λειτουργεί χωρίς λογαριασμό, cookies, αποστολή προσωπικών δεδομένων ή εξωτερικό API. Χρησιμοποίησε μόνο την ύλη που θα σου δώσω. Μην επινοήσεις σχολικές πηγές. Δείξε πρώτα το σχέδιο και μετά τον κώδικα. Παρουσίασε τον τρόπο ελέγχου κάθε απάντησης.

Κόστος και περιορισμοί

Ηλικία: 18 ετών και άνω. Δεν το προτείνουμε για αυτόνομη χρήση από μαθητές. Υπάρχει δωρεάν ατομικό πλάνο με όρια χρήσης· η διαθεσιμότητα και οι δυνατότητες μπορεί να μεταβληθούν. Επιβεβαίωσε τις ισχύουσες προϋποθέσεις στη Google.
  • Μπορεί να παράγει εσφαλμένο κώδικα ή εκπαιδευτικό περιεχόμενο.
  • Οι agents μπορούν να εκτελούν εντολές και να τροποποιούν αρχεία: έγκρινε τις ενέργειες, κράτα αντίγραφα και απόφυγε αυτόματη δημοσίευση.
  • Μην καταχωρίζεις ονόματα, εργασίες με προσωπικά στοιχεία μαθητών, κωδικούς, API keys ή ευαίσθητα σχολικά δεδομένα.
  • Ο έλεγχος προσβασιμότητας και ασφάλειας είναι ευθύνη του εκπαιδευτικού. Δεν έχουμε επαληθεύσει ειδική δήλωση προσβασιμότητας για το προϊόν.

Επίσημες πληροφορίες: Λήψη · Τεκμηρίωση · Κόστος.

Google Antigravity

Building educational apps with AI — A practical educator guide

A practical guide for educators, museum professionals, curators and cultural organisations exploring AI-assisted development.

Official Antigravity website

What is it?

Google Antigravity is an AI-agent development environment that can assist with code, small applications and testing. It is not a ready-made learning platform.

Practical uses in education and cultural heritage

  • Build interactive revision quizzes.
  • Create simple educational websites and activities.
  • Test digital teaching materials.
  • Prototype interactive museum exhibits, digital storytelling and visitor learning activities.
  • Explore software development workflows.

First steps

  1. Check requirements and installation instructions on the official website.
  2. Create a separate test project, not a live school website.
  3. Ask: “Create a 10-question Physics quiz with feedback, using HTML, CSS and JavaScript, collecting no personal data.”
  4. Request a preview and test every answer yourself.
  5. Correct errors before use with students.

Try this prompt

Create an accessible bilingual (Greek/English) quiz webpage for primary-school fractions. Include 8 questions, explanations after each answer, a “Try again” button and mobile-friendly layout. Use no accounts, cookies, personal data collection or external APIs. Use only the lesson material I provide and do not invent sources. Show a plan before writing code and explain how I can verify every answer.

Cost, eligibility and limits

For users aged 18 or older only. There is a free individual tier subject to usage limits. Terms and availability can change.
  • Generated code and instructional content can be wrong.
  • Agents can change files and execute commands. Review permissions, keep backups and avoid automatic production deployment.
  • Never provide student personal information, credentials or secrets.
  • Educators must independently check accessibility, privacy and safety. No dedicated accessibility conformance statement has been verified for this tool.
