Before you start: Antigravity is available only to users aged 18 or older. Never upload identifiable student or visitor information, unpublished sensitive records, passwords or API keys. Depending on permissions, agents can modify files and run system commands.

What is Antigravity 2.0?

Google introduced Antigravity 2.0 on 19 May 2026 as a standalone AI-agent management application for Windows, macOS and Linux. It is not simply a new name for the original IDE. Agents can work across projects, read and write files, use tools and terminal commands, research online and interact with a browser. Users define access permissions and review actions.

Antigravity 2.0 vs Antigravity IDE

Antigravity 2.0: Agent application

An agent-first command centre for conversations, projects, parallel tasks, subagents and controlled access to folders, browsers and commands. It is not a conventional code editor.

Antigravity IDE: Coding environment

A separate IDE with a code editor, file explorer, tabs and software development tools. It remains available for developers who want to inspect and edit code directly.

Which version do I have installed?

If your app mainly shows Projects and agent conversations, it is likely Antigravity 2.0. If you see a code editor, tabs and a file explorer, you likely have the IDE. Google also describes a white-background app icon for 2.0 and a dark-grid icon for the IDE. Check the product name/version in About or on the downloads page because icons can change.

Google says existing IDE installations may update to 2.0 and offer an option to keep the IDE as well.

Practical applications

Educators

Prototype interactive quizzes, simulations, exercises and educational websites with a clearly defined learning objective.

Museum professionals and curators

Experiment with digital exhibits, timelines, interactive interpretation and visitor learning activities.

Researchers

Organise local files and prototype documentation workflows or source checking tools. These do not replace scholarly verification.

Cultural heritage organisations

Prototype small applications, websites and workflows, with accessibility, provenance and rights review.

What does the free plan include?

Google offers a $0/month individual tier with basic weekly usage limits. This does not mean unrestricted or permanently guaranteed access to every model or feature. Paid options provide higher limits. Quotas and availability may change; check the official pricing page.

Getting started safely

  1. On the official downloads page, choose Antigravity 2.0 or Antigravity IDE according to your needs.
  2. Sign in with an eligible adult Google Account. Check the system and geographic availability requirements.
  3. Create a separate test Project and add only the folders an agent truly needs. Keep backups.
  4. Use narrowly scoped permissions and manual approval for commands. Avoid unrestricted access or automatic production deployment.
  5. Ask for a plan first, then a prototype, then tests. If using browsing or scheduled tasks, review the permissions and actions involved.
  6. Validate every answer, link and interaction. Before publication, check educational accuracy, historical evidence, sources and rights, accessibility, and privacy.

Ready-to-use prompt for educators

Replace the placeholders in square brackets and provide lesson materials you have already verified. The example asks for a classroom activity, not an automatic deployment.

Help me create an accessible interactive learning activity for students in [grade], for [subject] and [specific unit]. Use only the official textbook or verified passages that I provide. If the source is missing or the unit mapping is uncertain, tell me and do not invent questions or references. First propose an eight-question quiz with a short explanation for every correct answer, constructive feedback on incorrect responses, a "Try again" button, full keyboard support and a mobile-friendly layout. It should work locally without accounts, cookies, student personal data or external APIs. Before writing code, show me your plan, the eight proposed questions, the correct answers and the exact supporting passage for each. Wait for my approval before editing files or running commands. Do not publish anything. Finish with functional, accessibility and educational accuracy checks and clearly identify anything you could not verify.

Example prompt: prototype an interactive digital exhibit

Create a local, bilingual (Greek/English) prototype of an interactive digital exhibit about the history of artificial intelligence. Build a timeline with selected events and a 'Learn more' interaction. Clearly distinguish established historical evidence, interpretation and reconstruction. Use only the verified sources and materials I provide; do not invent citations, free-to-use images or historical claims. Do not use personal data, external APIs or cookies. Present a plan first and do not change unrelated files or deploy anything without my approval. Finally, provide desktop/mobile functional checks and a list of unresolved issues.

Limitations and responsible use

  • Agents can modify real files and run system commands. Project permissions are important.
  • AI-generated code, summaries and citations may be wrong or insecure.
  • For museum work, review rights separately for collection objects, photos, illustrations, videos and reproductions.
  • Do not grant uncontrolled permissions to publish, delete files or access confidential records.
  • Antigravity is for adults; any learning material created for minors requires independent review before classroom use.
