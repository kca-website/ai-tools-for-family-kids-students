EduVideo Studio v0.7 — Portable Windows 11 (x64)
================================================

ΑΥΤΕΣ ΟΙ ΟΔΗΓΙΕΣ ΙΣΧΥΟΥΝ ΜΟΝΟ ΓΙΑ ΤΟ ΠΛΗΡΕΣ ΠΑΚΕΤΟ ΤΟΥ WINDOWS BUILD (όχι το πηγαίο ZIP).
Αποσυμπίεσε ΟΛΟΚΛΗΡΟ τον φάκελο, διατηρώντας τους υποφακέλους:
  EduVideoStudio.exe
  piper/ (ενσωματωμένη μηχανή φωνής)
  voices/ (ελληνικό και αγγλικό μοντέλο)
  bin/ffmpeg.exe (μηχανή MP4)

Άνοιξε EduVideoStudio.exe. Κανένα πρόγραμμα ή Python δεν χρειάζεται εγκατάσταση.
Η εξαγωγή λειτουργεί τοπικά, χωρίς internet ή κλειδιά API, όταν έχουν ήδη
συμπεριληφθεί όλα τα αρχεία στο πακέτο.

1. Επικόλλησε εκπαιδευτική ύλη ή άνοιξε TXT, MD, DOCX.
2. Επίλεξε 1, 2, 3 ή 5 λεπτά και Ελληνικά/English.
3. Πάτησε Δημιουργία σεναρίου και διόρθωσε το κείμενο δεξιά.
4. Πάτησε Εξαγωγή MP4. Στον ίδιο φάκελο θα σωθεί και SRT.

Σημαντικό: ΔΕΝ υπάρχει ακόμη generative AI για σύνθεση σεναρίου, επομένως
οι 1/2/3/5 επιλογές ρυθμίζουν την έκταση που επιλέγεται από το κείμενο,
όχι την ακριβή διάρκεια τελικού MP4. Τα γραφικά είναι διαφάνειες, όχι
γενετικά κινούμενα βίντεο. Δεν υποστηρίζεται ακόμη PDF.
Η ποιότητα της φωνής εξαρτάται από τα τοπικά μοντέλα Piper.

ΠΡΟΣΟΧΗ: Αν έχεις ΜΟΝΟ το EduVideoStudio.exe χωρίς τους φακέλους
φωνής/FFmpeg, αυτό ΔΕΝ είναι πλήρης εφαρμογή και δεν κάνει εξαγωγή.

Υπότιτλοι: τμηματοποίηση σε μικρές φράσεις με ΠΡΟΣΕΓΓΙΣΤΙΚΟ συγχρονισμό ανά λέξεις, όχι ακριβή χρονική ευθυγράμμιση φωνημάτων.
